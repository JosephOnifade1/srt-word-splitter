# GitHub Setup Guide for SRT Word Splitter

This guide walks you through creating and optimizing your GitHub repository for maximum discoverability.

---

## Step 1: Create New Repository

1. Go to **GitHub.com** and log in
2. Click **+** (top right) → **New repository**
3. Repository name: `srt-word-splitter`
4. Description (copy this):
   ```
   Automatically split SRT subtitles into 2-3 word chunks with perfect timing. 
   Perfect for YouTube Shorts, TikTok, and faceless content creators.
   ```
5. Make it **Public**
6. Click **Create repository**

---

## Step 4: Upload Files

1. Create a folder on your computer
2. Add these files:
   - `srt_word_splitter.py` (the main script)
   - `README.md` (documentation)
   - `LICENSE` (MIT license)
   - `.gitignore` (ignore unnecessary files)
   - `example.srt` (example file for testing)

3. Go to GitHub repository page
4. Click **Add file** → **Upload files**
5. Drag and drop all files
6. Commit with message: "Initial commit: Add SRT Word Splitter"
